# IPL_2024_ANALYSIS

# 🏏 IPL 2024 Data Analysis with Power BI

This project provides a comprehensive analysis of **IPL 2024** player and team performance using **Power BI** and player statistics. The report breaks down batting and bowling metrics across roles, styles, and match scenarios to uncover performance trends, patterns, and standout players from the season.

---

## 📊 Project Objectives

- Analyze **batting performance** by strike rate, boundary %, average, and balls faced.
- Evaluate **bowling performance** by wickets, economy, strike rate, and dot ball %.
- Categorize players as **Power Hitters, Anchors, Finishers, All-Rounders**, and **Fast Bowlers**.
- Compare player performance in different match conditions:
  - **Batting First vs Bowling First**
  - **Top-order vs Lower-order contributions**
- Help users select an ideal **Playing 12** based on performance metrics.

## 🧪 Insights from the Dashboard

The dashboard is fully **interactive** and designed for exploration. All filters and slicers — such as **batting position**, **player role**, **team**, **match condition** (batting first or bowling first), and more — are **completely dynamic**. Users can toggle these filters to customize the data view and uncover unique insights.

You’re not limited to predefined visuals — you can:

- 🔍 **Drill down into individual player stats**
- 🎯 **Compare players based on batting or bowling metrics**
- 🧠 **Experiment with combinations to build your ideal Playing 11**

Whether you're curious about top finishers, the most economical bowlers, or boundary-heavy openers, the dashboard lets you filter and analyze based on **what matters most to you**.

---

## 🧠 Playing 12 Recommendation

The dashboard features an interactive "Playing 12" builder where users can select players based on key metrics to assemble their ideal IPL team.

---

## 📥 How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Use slicers and filters to explore trends.
4. Analyze players and build your own Playing 12.
